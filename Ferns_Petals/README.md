# Excel Data Analysis Project with AI 

## Project Description
This project demonstrates a complete end-to-end data analysis process using Microsoft Excel.  
All stages of the analysis, from raw data cleaning to building an interactive business dashboard, were completed by **Khaled Aboelatta**.

The project analyzes e-commerce data to uncover insights about sales performance, customer behavior, top products, and revenue trends.  
It is fully designed, modeled, and implemented in **Arabic**, providing one of the most comprehensive Arabic-language Excel data analysis projects available.

---

## Project Objectives
- Perform complete data cleaning and transformation using **Power Query**.
- Build data models with relationships between multiple tables (Orders, Customers, Products, etc.).
- Create calculated columns and measures using **DAX** and **Power Pivot**.
- Develop an interactive dashboard that presents meaningful **business KPIs** and visual insights.

## Key Analysis Steps
1. **Data Cleaning and Transformation**  
   - Removed duplicates and missing values.  
   - Standardized column names and formats.  
   - Created calculated columns such as:
     - `Revenue = Price × Quantity`
     - `Delivery Days = Delivery_Date - Order_Date`
     - `Month` and `Hour` fields for time-based analysis.

2. **Data Modeling**  
   - Established relationships between Orders, Customers, and Products tables.  
   - Implemented a star schema model to ensure efficient data analysis.

3. **Data Analysis and Visualization**  
   - Used **Pivot Tables** and **Pivot Charts** for summarization.  
   - Designed a dashboard using slicers and charts to enable interactive exploration.  
   - Created key business KPIs, including:
     - Total Revenue  
     - Average Delivery Time  
     - Top Products by Sales  
     - Monthly Sales Trends  
     - Customer Spending Patterns
