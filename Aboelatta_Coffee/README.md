# Aboelatta Coffee – Excel Data Analysis & Dashboard Project

## Project Overview

This project presents a complete **data analysis and interactive dashboard** for **Aboelatta Coffee**, designed and developed entirely in **Microsoft Excel**.
The goal of this project was to transform raw and unstructured data into meaningful business insights that support better decision-making.

The process covered **data cleaning, transformation, modeling, and visualization**, resulting in a fully dynamic and automated dashboard.

---

## Data Preparation

The dataset initially existed in image format and was manually converted into structured Excel data.
Afterward, several steps were performed to ensure data quality and consistency:

* Converting data from image to structured Excel tables
* Cleaning missing or inconsistent values
* Standardizing date and product formats
* Adding calculated fields for performance tracking
* Building relationships between data tables

---

## Automation and Interactivity

To make the dashboard fully interactive, **Excel Macros (VBA)** were implemented.
The macros allow smooth navigation between different dashboard sections by clicking buttons, making the user experience intuitive and dynamic.

---

## Key Performance Indicators (KPIs)

The dashboard tracks several important business metrics to evaluate store performance, including:

* **Total Sales Revenue**
* **Number of Active Products and Categories**
* **Top-Selling Products**
* **Most Active Sales Days**
* **Average Daily Sales**
* **Customer Order Trends**
* **Revenue Distribution by Category or Day**

---

## Tools and Techniques Used

* Microsoft Excel
* Power Query (for data cleaning and transformation)
* Data Model (for relationships and analysis)
* Pivot Tables and Pivot Charts
* VBA Macros (for interactivity and automation)
* Conditional Formatting and Dynamic Filters

---

## Project Outcomes

The **Aboelatta Coffee Dashboard** provides a clear, interactive overview of sales and performance metrics.
It allows quick exploration of data trends, helping identify best-selling items, peak working days, and areas for improvement.
